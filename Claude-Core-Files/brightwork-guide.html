Brightwork Component Reference

Your complete guide to building new pages in Elementor using Brightwork's CSS classes and shortcodes. Every component shown here is available once the two child theme files are installed.

00Setup — 3 Steps, ~5 Minutes

Install two files in your child theme, then add one line to functions.php. After that every shortcode and CSS class in this guide is available on every page.

1

Upload both files to your child theme folder via FTP or File Manager (wp-content/themes/YOUR-CHILD-THEME/):
brightwork-elementor.css  &  brightwork-shortcodes.php

2

Open your child theme's functions.php (Appearance → Theme File Editor) and add this single line anywhere inside it:
require_once get_stylesheet_directory() . '/brightwork-shortcodes.php';
This loads the CSS automatically and registers all shortcodes.

3

Done. Create any new WordPress page, open it in Elementor, and start using the classes and shortcodes below. No template file needed — you build the layout in Elementor and apply Brightwork styling through CSS classes and shortcode widgets.

How CSS classes work in Elementor Free: Select any Section, Column, or Widget → click the Advanced tab in the left panel → type the class name(s) in the "CSS Classes" field (space-separated for multiple). The styling applies instantly on save.

How shortcodes work in Elementor Free: Add a Shortcode widget to any section (search "shortcode" in the Elementor widget panel), then type the shortcode into the field. The component renders on the frontend.

09Wave Dividers

Add a Shortcode widget between sections. Set from/to to match the background colors of the sections above and below it. Remove all padding from the shortcode widget's Advanced settings.

Available transitions
[bw_wave from="fog" to="white"]       ← fog section → white section
[bw_wave from="white" to="navy"]      ← white section → navy section
[bw_wave from="navy" to="fog"]        ← navy section → fog section
[bw_wave from="navy" to="dark"]       ← navy → dark gradient (footer CTA)
[bw_wave from="dark" to="white"]      ← dark → white
[bw_wave from="fog" to="navy"]        ← fog → navy
[bw_wave from="white" to="dark"]      ← white → dark gradient
[bw_wave from="dark" to="fog"]        ← dark → fog
10Building a New Page — Workflow

Here's the exact sequence to recreate any Brightwork page layout in Elementor Free.

1

Create a new WordPress Page, give it a title, and open it in Elementor. Set Page Layout to "Elementor Canvas" or "Full Width" in Page Settings (⚙ icon bottom left).

2

Add a Shortcode widget at the very top of the page and type [bw_progress_bar]. This adds the teal/gold scroll progress bar.

3

Add a Section, open Advanced → CSS Classes, and type the background class: bw-section-hero, bw-section-white, bw-section-navy, etc.

4

Inside the section, add columns and widgets normally. Apply typography classes to Heading and Text widgets via Advanced → CSS Classes. Use bw-card-fog or bw-card-dark on columns for the card look.

5

Add a Shortcode widget between sections for wave transitions: [bw_wave from="white" to="navy"]. Set its top/bottom padding to 0px in the Layout tab.

6

Use Shortcode widgets for complex components — eyebrows, pillar cards, stat boxes, process steps, quote blocks, and buttons. Place them inside columns.

7

Wrap sections or widgets in [bw_animate]...[/bw_animate] for scroll reveal animations. The JS in the shortcodes file handles the reveal automatically.

Pro tip: Once you build one section you're happy with, right-click it in Elementor and choose Save as Template. You can then drag it into any future page and just swap the text — the styling is already set.
